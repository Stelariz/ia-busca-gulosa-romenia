# ia-busca-gulosa-romenia
Implementação em Python do algoritmo de Busca Gulosa pela Melhor Escolha, explorando o problema clássico de rotas da Romênia (Russell &amp; Norvig). O algoritmo prioriza a heurística de menor distância em linha reta para alcançar o objetivo rapidamente, demonstrando a tomada de decisão focada na recompensa imediata.
